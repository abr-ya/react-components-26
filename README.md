# Component Library

A React component library built with Tailwind CSS and TypeScript.

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 📦 What's Inside

- **React 18** + **TypeScript**
- **Vite 6** (lib-mode build: ESM + CJS)
- **Tailwind CSS 3** + **lucide-react** (icons)
- **Vitest** (tests)
- **ESLint** + **Prettier** (code quality)
- **Husky** (pre-commit hooks)

## 📁 Structure

```
src/
├── components/    # Library components
├── lib/           # Utilities (cn, types)
└── test/          # Tests
```

## 🛠 Commands

| Command | Description |
|---------|----------|
| `npm run dev` | Dev server for testing |
| `npm run build` | Build the library (dist/) |
| `npm run test` | Run tests |
| `npm run lint` | Check code |
| `npm run format` | Format code |
